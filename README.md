# Рой ИИ-агентов

Система из 8 ИИ-агентов, которые автоматически помогают вести социальные сети.
Вы ставите задачу — «рой» её решает: пишет тексты, придумывает сценарии, планирует публикации.

---

## Что умеет система

- **Прогон роя** — задаёте цель (например, «сделай пост о нашем новом продукте»), Стратег составляет план, остальные агенты выполняют задачи по очереди, Критик проверяет результаты
- **Прямая задача** — обращаетесь к конкретному агенту напрямую, без плана
- **Чат с агентом** — разговариваете с любым агентом как с экспертом
- **Инбокс идей** — складываете идеи «на потом», запускаете когда нужно
- **База знаний** — загружаете файлы о вашем бизнесе, агенты используют эту информацию
- **Контент-план** — черновики публикаций с календарём, публикация в Telegram-канал
- **Telegram-бот** — управляете всем прямо из телефона
- **Тесты агентов** — проверяете качество ответов агентов автоматически

## Запуск с нуля

### 1. Запустите базу данных

Перед каждой работой с проектом нужно запустить PostgreSQL:

```
"D:\pgsql\bin\pg_ctl.exe" -D "D:\pgsql\data" -l "D:\pgsql\data\logfile.log" start
```

### 2. Установите зависимости (один раз)

```
npm install
```

### 3. Создайте файл с секретами (один раз)

Скопируйте `.env.example` в `.env` и заполните значения:

```
DATABASE_URL=postgresql://swarm:swarm@localhost:5432/ai_agent_swarm
BACKEND_PORT=4000
NEXT_PUBLIC_BACKEND_URL=http://localhost:4000
ANTHROPIC_API_KEY=ваш_ключ_от_anthropic.com
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_OWNER_CHAT_ID=ваш_chat_id  (узнать: npm run telegram:chat-id)
TELEGRAM_CHANNEL_ID=@ваш_канал
```

### 4. Создайте базу данных (один раз)

```
npm run db:setup
npm run db:seed
npm run db:migrate
```

### 5. Запустите проект

```
npm run dev
```

## Telegram-бот — команды

```
/help          — справка
/project demo  — переключиться на проект «demo»
/runs          — последние прогоны
/idea текст    — добавить идею (появятся кнопки 🚀 и ❌)
/inbox         — показать все идеи с кнопками
/task scriptwriter напиши пост про кофе  — прямая задача агенту
/agent critic  — начать диалог с агентом
/cancel        — выйти из диалога
```

## Полезные команды

```bash
# Запуск
npm run dev                   # запустить всё (бэкенд + дашборд)

# База данных
npm run db:migrate            # применить обновления (после обновлений)
npm run db:backup             # сделать резервную копию

# База знаний
npm run knowledge:ingest -- --dir=./docs --project=demo

# Тесты агентов
npm run tests:seed            # создать базовые тестовые сценарии
npm run tests:batch           # прогнать тесты

# Утилиты
npm run api -- GET health     # проверить API (вместо curl)
npm run telegram:chat-id      # узнать свой Telegram chat ID
npm run typecheck             # проверить код на ошибки
```

## Если что-то сломалось

**База данных не отвечает** — скорее всего не запущен PostgreSQL. Запустите командой выше.

**Порт занят** — уже запущен другой экземпляр. Закройте и запустите заново.

**Агенты не отвечают** — проверьте `ANTHROPIC_API_KEY` в файле `.env`.

**Telegram-бот молчит** — проверьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_OWNER_CHAT_ID`.
